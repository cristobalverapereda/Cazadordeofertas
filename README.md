# Cazador de Ofertas Android

Repositorio de compilación APK.

## Uso

1. Sube a la raíz el archivo `CazadorDeOfertasAndroid_source.zip` (sin descomprimir), desde **Add file → Upload files**.
2. GitHub Actions ejecutará **Compilar APK Android** automáticamente con el nuevo commit; también puede iniciarse desde **Actions → Compilar APK Android → Run workflow**.
3. Si la ejecución pasa, descarga `CazadorDeOfertas-APK` y extrae `app-debug.apk`.

No subas claves de SerpApi. El APK es de depuración y las búsquedas requieren configuración posterior de SerpApi.
